Vocabulário (docs/design-system.md): info círculo azul de informação — ação neutra, sem consequência a destacar (ex. autorizar, enviar, separar para retirada). warning triângulo âmbar de atenção — pede cuidado redobrado antes de confirmar (ex. retornar para rascunho, atender retirada, que baixa estoque físico). danger círculo vermelho de alerta — recusar/cancelar. Encerram a requisição, mas a trilha é append-only: nenhuma delas apaga um registro (CONTEXT.md). O estorno saiu daqui: esta linha listava "estornar" enquanto a linha de `return` logo abaixo dizia que reversão operacional nunca usa o vocabulário de perigo — os dois parágrafos deste mesmo comentário se contradiziam. descarte lixeira vermelha — reservada à única operação que remove um registro sem rastro: o descarte de rascunho sem número público. Antes do #136, `danger` inteiro usava este glifo, e cancelar/ recusar/estornar diziam "isto vai para o lixo" sem que nenhuma delas apagasse nada. return seta teal de devolução — Regra da Reversão Não é Erro: reversão operacional nunca usa o vocabulário visual de erro/perigo.
