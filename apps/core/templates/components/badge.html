{% comment %} Componente global de badge/pill. Não conhece enums de domínio — só variante visual. Partials de domínio (ex. _estado_badge.html) mapeiam estado -> variant/label/role/aria_label. Parâmetros: variant (obrigatório) slate, blue, blue-strong, amber, amber-strong, green, red, red-strong, orange, teal, indigo, violet, yellow label (obrigatório) texto do badge prefixo_sr (opcional) texto só-leitor-de-tela antes do label, para dar contexto ao dado ("Estado: ", "Tipo: "). Preferir a `aria_label`: `aria-label` num sem role é `role=generic` e a spec ARIA não garante que seja exposto. role (opcional) propagado literalmente como role="{{ role }}". NÃO usar `status`/`alert` em badge de dado estático: são live regions, e uma listagem de 20 linhas viraria 20 live regions.
