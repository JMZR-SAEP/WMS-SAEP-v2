{% comment %} Sumário de erros no topo do formulário. Existe porque re-renderizar um formulário longo com os erros só inline não identifica a falha: no celular do solicitante o campo inválido pode estar três roladas abaixo, e a tela volta aparentemente intacta. O sumário resolve as três pontas — anuncia que falhou, diz quantos e quais, e leva ao campo por link. Padrão GOV.UK: `role="alert"` + `tabindex="-1"` + foco no mount. O foco é o que funciona de verdade após um POST — conteúdo já presente no carregamento não dispara live region; é a mudança que dispara. `role="alert"` cobre o caso de o sumário aparecer via swap HTMX, em que há mudança. Parâmetros: erros (obrigatório) lista de {id, rotulo, mensagem}, montada por {% coletar_erros form formset ... as erros %} (core_tags). Vazia ou ausente não renderiza nada. id (opcional, default "sumario-erros") útil se houver dois formulários na mesma tela.
