{% comment %} Bloco de confirmação de uma ação de fluxo da requisição (autorizar, recusar, cancelar, estornar, retornar). Cada instância é autocontida: painel de decisão + modal de confirmação, envolvidos no mesmo x-data="modalController(...)" — é o escopo compartilhado que faz o botão do painel abrir o modal ao lado. A superfície visível vive em requisicoes/partials/_painel_decisao.html, que é quem documenta layout, variante, nome acessível e fallback. Este arquivo é só a composição. Parâmetros repassados ao painel: layout, variant_token, titulo, conteudo, modal_id, heading_id, botao_label, botao_variant, botao_icon Parâmetros próprios da composição: abrir_ao_carregar_expr (opcional) expressão já resolvida (ex.: `erro|yesno:"true,false"`) para abrirAoCarregar no x-data Os parâmetros abaixo são repassados diretamente a components/modal.html: modal_titulo, modal_descricao, action_url, confirm_label, confirm_variant, icon_variant, form_body_template, hidden_inputs, erro, motivo_recusa, form Uso (card): {% include "requisicoes/partials/_confirmacao_acao.html" with layout="card" variant_token="info" modal_id="confirmar-autorizar" titulo="Autorização integral" conteudo="Aprove a requisição e reserve o saldo necessário para todos os itens." botao_label="Autorizar" botao_variant="primary" modal_titulo="Autorizar requisição?" modal_descricao="..." action_url=autorizar_url confirm_label="Confirmar autorização" confirm_variant="primary" icon_variant="info" hidden_inputs=autorizar_hidden_inputs %} Uso (banner): {% include "requisicoes/partials/_confirmacao_acao.html" with layout="banner" variant_token="danger" heading_id="estornar-titulo" modal_id="estornar-modal" titulo="Estornar requisição" conteudo="..." botao_label="Estornar requisição" botao_variant="danger-outline" botao_icon="components/icons/estornar.svg" modal_titulo="Estornar requisição" modal_descricao="..." action_url=estornar_url confirm_label="Confirmar estorno" confirm_variant="danger" form=estorno_form form_body_template="requisicoes/partials/_modal_form_estorno.html" %} {% endcomment %}
